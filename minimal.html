Abstract

In high-stakes settings, practitioners need not only accurate models but honest uncertainty about each prediction. The usual tools, log-probabilities, sampling, and fine-tuning, are exactly what a closed API withholds.

Pinocchio is a suite of 8B checkpoints that assigns an uncertainty estimate to any model's prediction using only the text of the response. It works on text LLMs and vision-language models, transfers across model families without retraining, and plugs into an existing pipeline in two additional lines. One judge scores even the newest black-box systems it never saw: Claude Opus 5, GPT-5.6, Kimi 3, and Fable 5.

The idea

Given a question Q and a candidate answer A, Pinocchio returns the probability that the answer is correct. It reads only the text, never the target model's weights or logits, so you can score outputs from OpenAI, Anthropic, Gemini, a local checkpoint, or vLLM with the same call.

How it works

Pinocchio is prompted for a binary verdict and reads P(correct) from the softmax over the next-token logits for ii (Yes) versus i (No):

$$\hat p(\text{correct})=\frac{e^{z_{\text{yes}}}}{e^{z_{\text{yes}}}+e^{z_{\text{no}}}}$$
Question: {Q} Answer: {A} Is the answer correct? (i) No (ii) Yes

We train the judge on a curated, difficulty-spread mixture of 15+ text benchmarks (GSM8K, BBEH, SimpleQA, GPQA, OmniMath, HLE) and 8 vision-language benchmarks (MathVista, MathVerse, CharXiv, MMMU, HallusionBench, VSR), so it sees confident successes and confident failures alike. Post-hoc temperature scaling sharpens calibration while preserving ranking.

Two lines of code

quickstart.pypython
from pinocchio import Judge

judge = Judge.from_pretrained("KevinDavidHayes/pinocchio-text-8b")

# Score any model's response: OpenAI, Anthropic, vLLM, local HF.
response = openai.chat.completions.create(model="gpt-5.6", messages=[...])
p_correct = judge.score(question, response.choices[0].message.content)

if p_correct < 0.5:
    log("Low confidence. Flag for human review.")

Same API for VLMs: pass an image alongside the question/response and load pinocchio-vlm-8b.

Results

What you get

pinocchio-text-8b

A single 8B calibrator, 0.878 AUROC on the hard suite, transferring zero-shot to 16 unseen models across 9 organisations.

pinocchio-vlm-8b

One checkpoint scores text and vision-language responses at comparable AUROC, with no separate per-modality model.

small & correctable

The 0.8B model keeps 99% of the 9B AUROC, and ~100 labels halve the calibration error on a new model.
