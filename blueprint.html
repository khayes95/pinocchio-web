Pinocchio

0.001.00

An instrument that measures whether a language model is telling the truth.

It reads only the text of an answer and returns the probability the answer is correct, with no log-probabilities, no extra samples, no access to weights. One judge scores even the newest black-box systems it never saw: Claude Opus 5, GPT-5.6, Kimi 3, Fable 5.

Sheet 02

Description

In high-stakes settings, practitioners need not only accurate models but honest uncertainty about each prediction. The usual tools (log-probabilities, sampling, fine-tuning) are exactly what a closed API withholds.

Pinocchio is a suite of 8B checkpoints that assigns an uncertainty estimate to any model's prediction using only the text of the response. It works on text LLMs and vision-language models, and transfers across model families without retraining.

We build it from a curated, difficulty-spread mixture of hard benchmarks so the judge sees both confident successes and confident failures, then it plugs into an existing pipeline in two lines.

Against black-box baselines it wins on calibration and discrimination, and generalises to the newest frontier systems whose responses it never trained on.

Sheet 03

Installation

quickstart.pypython
from pinocchio import Judge

judge = Judge.from_pretrained("KevinDavidHayes/pinocchio-text-8b")

# Score any model's response: OpenAI, Anthropic, vLLM, local HF.
response = openai.chat.completions.create(model="gpt-5.6", messages=[...])
p_correct = judge.score(question, response.choices[0].message.content)

if p_correct < 0.5:
    log("Low confidence. Flag for human review.")

Same interface for VLMs: pass an image alongside the question/response and load pinocchio-vlm-8b.

Bill of materials

01

One transferable judge

A single 8B calibrator reaches 0.878 AUROC on the hard suite. Trained only on older models, it transfers zero-shot to 16 unseen models across 9 organisations, the four newest frontier systems among them.

02

Text and vision, one checkpoint

The same judge scores text-LLM and vision-language responses at comparable AUROC, so a deployer needs no separate per-modality model.

03

Small, and easy to correct

The 0.8B calibrator keeps 99% of the 9B model's AUROC, and roughly 100 target labels halve the calibration error on a new model.

Sheet 05

Principle of operation

Given a question Q and candidate answer A, the judge is prompted for a binary verdict and reads P(correct) from the softmax over the next-token logits for ii (Yes) versus i (No):

$$\hat p(\text{correct})=\frac{e^{z_{\text{yes}}}}{e^{z_{\text{yes}}}+e^{z_{\text{no}}}}$$

It never touches the target model's internals, only its text. Post-hoc temperature scaling sharpens calibration while preserving ranking.

Question: {Q} Answer: {A} Is the answer correct? (i) No (ii) Yes

Training mix: 15+ text benchmarks (GSM8K, BBEH, SimpleQA, GPQA, OmniMath, HLE, …) and 8 vision-language benchmarks (MathVista, MathVerse, CharXiv, MMMU, HallusionBench, VSR, …), difficulty-spread so the judge sees confident successes and confident failures alike.
