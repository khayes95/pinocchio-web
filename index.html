Uncertainty for black-box language models

Pinocchio

Fast uncertainty estimates for any LLM or VLM, in two lines of code.

Closed API models do not return log-probabilities and cannot be fine-tuned, which rules out most ways of estimating uncertainty. Their own stated confidence is poorly calibrated.

Pinocchio is a separate, lightweight model that reads a question and an API model's answer and predicts whether that answer is correct. One forward pass, no logits, no sampling, no access to the target model. It handles vision-language inputs and transfers to models it was never trained on.

Usage

pythontwo lines to add
from pinocchio import Judge

judge = Judge.from_pretrained("KevinDavidHayes/pinocchio-text-8b")

response = openai.chat.completions.create(model="gpt-5.6", messages=[...])
p_correct = judge.score(question, response.choices[0].message.content)
